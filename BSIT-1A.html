WHAT IS A COMPUTER SYSTEM?

Understanding the basics before entering the next level.

A computer system is a combination of hardware and software that works together to receive input, process data, store information, and produce output.


The physical parts of a computer are called hardware, while the programs and instructions that control those parts are called software. Both are important because hardware provides the physical resources while software tells the computer what tasks to perform.

[ LEVEL 01 / HARDWARE ]

HARDWARE COMPONENTS

The physical parts that make a computer system work.

CPU

Central Processing Unit

The CPU is the main processor of a computer. It executes instructions, performs calculations, and processes data based on the instructions provided by software.

FUNCTION: Executes instructions and processes data.
RAM

Memory

Random Access Memory, or RAM, temporarily holds data and instructions that the computer is actively using.

FUNCTION: Provides temporary working space for active programs and data.
SSD

Storage Devices

Storage devices keep files, programs, operating system data, and other information even when the computer is turned off.

EXAMPLES: SSD, HDD, USB flash drive, and memory cards.
IN

Input Devices

Input devices allow users to provide data and commands to the computer.

EXAMPLES: Keyboard, mouse, microphone, scanner, and webcam.
OUT

Output Devices

Output devices communicate processed information from the computer to the user.

EXAMPLES: Monitor, printer, speakers, projector, and headphones.

[ LEVEL 02 / SOFTWARE ]

COMPUTER SOFTWARE

The instructions that make computer hardware useful.

⚙ SYSTEM SOFTWARE

System software manages computer hardware and provides the environment needed for applications to operate.

  • Operating Systems
  • Device Drivers
  • Utility Programs
  • System Management Tools

♡ APPLICATION SOFTWARE

Application software is designed to help users perform specific tasks.

  • Web Browsers
  • Word Processors
  • Spreadsheet Applications
  • Graphic Design Programs
  • Games and Entertainment Apps

Simple way to remember: Hardware is the physical part of the computer, while software is the set of instructions that tells the hardware what to do.

[ LEVEL 03 / PROCESS ]

HOW COMPUTERS WORK

Follow the basic information-processing cycle.

STEP 01

INPUT

Data or commands enter the computer through input devices such as keyboards and mice.

STEP 02

PROCESS

The CPU processes the data according to instructions from software.

STEP 03

OUTPUT

The computer presents the processed information through an output device.

STEP 04

STORAGE

Data and results can be saved in storage devices for future use.

♡ REAL-WORLD EXAMPLE: TYPING A DOCUMENT
INPUT

Keyboard

You press a key on the keyboard. The keyboard sends the corresponding input to the computer.

PROCESS

CPU + RAM

The CPU processes the keyboard input while RAM temporarily holds the active data and instructions.

OUTPUT

Monitor

The monitor displays the character or text so the user can see the result.

STORAGE

Storage

When the document is saved, its data is stored on an SSD, HDD, or another storage device.
